# Control de Gastos - App en React Native

Este proyecto forma parte de las prácticas del curso, enfocándose en la conexión de una aplicación móvil con una API local para el envío y registro de datos.

- **Conexión cliente-servidor:** Aprendí a comunicar la aplicación móvil (corriendo en un emulador) con un servidor local en la computadora para enviar información de gastos mediante una petición POST.
- **Uso de servidor local:** Con la API local simulé una base de datos propia donde se guardan los registros (`/gastos`).
- **Resolución de problemas:** Aprendí a destrabar puertos en la computadora cuando quedaban ocupados y a entender cómo hacer que el emulador del celular y la PC se comuniquen correctamente por red.
